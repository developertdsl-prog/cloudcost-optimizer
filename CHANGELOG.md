## [1.0.0] - 2023-12-22

### Added
- Core Multi-Cloud FinOps discovery engine across AWS, GCP, and Azure.
- Kubernetes Pod Right-Sizing Engine calculating P95 CPU & Memory optimization.
- Real-time Spot Instance Arbitrage & interruption risk scoring engine.
- Cloud Waste & Zombie Resource Detector (unattached disks, idle IPs, orphaned snapshots).
- Statistical Cost Anomaly Detector with 2.5-sigma dynamic spike thresholding.
- Monthly spend linear regression forecaster against team budgets.
- Executive React 18 FinOps Command Center Dashboard.
- 7 automated unit and end-to-end test suites with 100% pass rates.
- Multi-stage Docker containerization and GitHub Actions automated CI workflow.
